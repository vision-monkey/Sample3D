개인정보처리방침

시행일: 2026년 10월 23일

업무포털(이하 "사이트")은 회원가입 없이 이용하는 미니게임 사이트입니다. 사이트는 이용자를 식별할 수 있는 정보를 최소한으로만 처리하며, 그 내용은 다음과 같습니다.

1. 처리하는 정보와 목적

항목목적보관 기간
닉네임, 그룹명, 게임 기록, 등록 일시순위표 표시 (모든 방문자에게 공개)삭제 요청 시까지
단체 이름, 단체 내 이름·그룹, 가입·최근 접속 일시단체 기능 제공 (같은 단체 멤버와 관리자에게만 공개)단체 탈퇴·내보내기 시 멤버 정보 삭제
IP 주소점수 조작·과도한 등록 방지 (등록 횟수 제한)최대 1일 후 자동 삭제
브라우저별 임의 ID, 방문·게임 시작·기록 등록 이벤트와 날짜방문 통계 집계13개월 후 자동 삭제

닉네임은 실명 대신 별명을 쓰도록 권장하며, 입력하지 않으면 임의의 별명이 자동으로 지정됩니다.

2. 브라우저 저장소 사용

입력한 닉네임·그룹명, 방문 통계용 임의 ID, 단체 멤버 확인용 토큰을 이용자 브라우저(로컬 저장소)에 저장합니다. 서버에는 토큰 원문이 아닌 변환값(해시)만 저장됩니다. 브라우저 설정에서 사이트 데이터를 지우면 함께 삭제됩니다.

3. 제3자 제공

처리하는 정보를 제3자에게 제공하지 않습니다. 단, 순위표에 등록한 닉네임·그룹명·기록은 사이트 특성상 누구나 볼 수 있습니다.

4. 처리 위탁

  • Supabase: 순위 기록·통계 데이터 저장
  • GitHub Pages: 사이트 호스팅

위 서비스는 국외(미국 등)의 서버를 이용할 수 있습니다.

5. 이용자의 권리

본인이 등록한 기록의 삭제를 요청할 수 있습니다. 아래 문의처로 닉네임, 게임, 등록 일시를 알려주시면 확인 후 삭제합니다.
